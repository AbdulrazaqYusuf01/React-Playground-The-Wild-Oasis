# The Wild Oasis

A staff-facing web application for managing hotel cabin bookings.  
Built with **React Query** and **Supabase** for a modern, fast, and scalable experience.

## Features

- View, create, and manage hotel cabin bookings
- Real-time data sync powered by Supabase
- Smooth and optimized data fetching with React Query
- Clean, responsive UI for hotel staff efficiency

## Tech Stack

- **Frontend:** React, React Query, TailwindCSS
- **Backend & Database:** Supabase
- **Deployment:** Netlify

## Live Demo

👉 [Visit The Wild Oasis](https://monsurathavenly.netlify.app)

## Getting Started (for local setup)

1. Clone the repository:

   ```bash
   git clone https://github.com/AbdulrazaqYusuf01/React-Playground-The-Wild-Oasis.git
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a .env file with your Supabase credentials.

4. Run the app locally:
   npm run dev
